FireBehaviorModels 2026/08/21

FireBehaviorModels includes runfspro, runflammap, runfarsite, runmtt, and runrandig apps

These apps can be run directly from the \bin directory, or alternatively run SetEnv.bat to set the system PATH as well as set environment variables GDAL_DATA, PROJ_LIB, and WINDNINJA_DATA for correct environment setup

Any use of the data derived from these applications requires the following citation:

"Fire behavior calculations produced with the command line fire behavior applications developed by the Missoula Fire Sciences Laboratory, Missoula, MT"
